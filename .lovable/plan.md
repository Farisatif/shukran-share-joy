# نظام ثيمات احترافي — نهاري/ليلي مع لون هوية ثابت

## الفكرة الأساسية

الموقع يستخدم بالفعل نظام تصميم قائم على CSS variables في `src/styles.css` (Tailwind v4 + `@theme inline`). لا حاجة لتعديل أي مكوّن — كل المكوّنات تقرأ من التوكنز تلقائيًا. المطلوب هو إعادة ضبط قيم التوكنز في كتلتي `:root` (نهاري) و `.dark` (ليلي) بشكل احترافي ومدروس.

## لون الهوية الثابت

```text
Primary (Indigo): oklch(0.55 0.22 268)
```
نفس القيمة بالضبط في الوضعين. يُستخدم تلقائيًا في:
- الأزرار الأساسية (`bg-primary`)
- المؤشرات النشطة (toggle اللغة، ring focus)
- نقطة الـ eyebrow وروابط التمييز
- الحلقات الإشعاعية (`pulse-ring`، `comments-spotlight`)

## 1) الوضع النهاري الأبيض

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `--background` | `oklch(0.99 0.002 255)` | خلفية ورقية نظيفة |
| `--foreground` | `oklch(0.16 0.018 260)` | نص حبر داكن |
| `--card` | `oklch(1 0 0)` | بطاقات بيضاء صافية |
| `--surface-1/2/3` | تدرّج رمادي خفيف جدًا | عمق بصري بدون ثقل |
| `--muted-foreground` | `oklch(0.5 0.018 258)` | نص ثانوي مقروء |
| `--border` / `--hairline` | رمادي ناعم | حدود أنيقة غير مزعجة |

## 2) الوضع الليلي الأسود

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `--background` | `oklch(0.13 0.006 268)` | أسود-فحمي بلمسة نيلية (لا أسود قاسٍ) |
| `--foreground` | `oklch(0.97 0.003 255)` | نص off-white مريح |
| `--card` | `oklch(0.17 0.008 268)` | طبقة أولى مرتفعة |
| `--surface-1/2/3` | 0.17 → 0.20 → 0.24 | 3 طبقات عمق متصاعدة |
| `--muted-foreground` | `oklch(0.7 0.012 258)` | تباين كافٍ بدون إجهاد |
| `--border` | `oklch(1 0 0 / 9%)` | حدود زجاجية شفافة |

## 3) الانتقال السلس

موجود مسبقًا في `body` (`transition: background-color 0.6s, color 0.6s`) وفي `.theme-anim` (transition شامل عند التبديل). سيُحتفظ به كما هو.

## ملفات سيتم تعديلها

- `src/styles.css` فقط — كتلتا `:root` و `.dark` (الأسطر 83-113 و 156-202 تقريبًا).

لن يُلمس أي مكوّن React. كل البطاقات، القوائم، الأزرار، والأقسام ستلتقط الثيم الجديد تلقائيًا عبر التوكنز.

## التحقق

- تشغيل `vite build` للتأكد من سلامة الـ CSS.
- المعاينة في الوضعين عبر زر التبديل الموجود في `ThemeLangToggle`.
